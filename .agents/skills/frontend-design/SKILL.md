# frontend-design — neutralizado en este repositorio

Este skill queda **neutralizado**. Este proyecto usa un sistema de diseño fijo:

- Fluent 2 (primary `#0078D4` / dark `#2899F5`)
- Tokens en `design/tokens.json` (Tailwind 4, `@theme` + `.dark`)
- Componentes en `src/components/ui/`

**No** elijas "una estética", **no** uses fuentes alternativas, **no** añadas
gradientes/texturas/sombras dramáticas. La consistencia viene del contrato, no del
"gusto" del modelo.

Carga el skill **`erp-design-contract`** y sigue `DESIGN.md`.
